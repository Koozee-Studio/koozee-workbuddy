# Koozee for WorkBuddy

Create fashion workflows on a free canvas. Batch-generate fashion images and videos.

在自由画布上创建时尚工作流，批量生成时尚图片和视频。

This repository is a WorkBuddy MCP + Skill connector. The clone root has `connector-meta.json`, `mcp.json`, `icon.svg`, and `skills/`.

- Product: [koozee.ai](https://koozee.ai)
- MCP: `https://koozee.ai/business-api/mcp` (`streamableHttp`)
- Minimum WorkBuddy: 4.24.0
- License: MIT

## Install

Clone this repository. The clone root is the connector root.

```bash
git clone https://github.com/Koozee-Studio/koozee-workbuddy.git
```

Import this folder as a WorkBuddy MCP + Skill connector. The first MCP connection uses OAuth. Calls without login return 401.

Credits match the Koozee canvas. After the canvas changes, open the project URL Koozee returns.
